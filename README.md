2048  - 纯原生微信小游戏

**零依赖，纯 JavaScript + Canvas 2D**，直接放入微信开发者工具即可运行。

## 项目结构

按功能拆分，`game.js` 只保留入口与核心棋盘逻辑：

```
2048-wechat-canvas/
├── game.js              # 入口：核心 Game（棋盘/移动/渲染编排/输入/难度弹框）
├── src/
│   ├── config.js        # 全部常量、GameState/StateTransitions、COLORS、调测开关
│   ├── tile.js          # Tile 方块实体
│   ├── special.js       # 特技加速：闪烁机会 / 特技池 / 弹窗 / 广告闭环 / 绘制
│   ├── ads.js           # 微信激励视频 SDK：初始化 / 加载 / 按场景展示与奖励
│   └── undo.js          # 后悔回撤：快照 / 回撤5步 / 免费次数 / 按钮绘制
├── game.json            # 微信小游戏配置
├── project.config.json  # 开发者工具项目配置
└── README.md
```

> 小游戏会自动执行 `game.js`，其余模块通过 `require('./src/xxx.js')` 加载；各模块同时兼容浏览器全局挂载（`window.FK_XXX`），方便本地调试。

## 难度系统

- 打开游戏首先显示圆角「选择难度」弹框，支持 **4×4 经典模式** 与 **5×5 挑战模式**。
- 点击即进入对应棋盘并开始新局；选择结果记录在 `fk2048_difficulty`，下次打开时在对应按钮上标注「上次使用」。
- 切换难度会重新布局棋盘、清空回撤历史并重置本局免费次数。

## 后悔回撤

- 棋盘下方一行：左侧「后悔」按钮，右侧缩短的特技池，两者同行且不超出棋盘左右边框。
- 点击「后悔」：**回撤最近 5 步**，棋盘与分数同步回滚（分数回到第 5 步移动前的快照）。
- **每盘局前 5 次免费**（按钮副标题显示「免费 ×N」）；第 6 次起需完整观看激励视频广告后生效。
- 广告中途关闭不生效，可再次点击重试。
- 失败弹窗打开时同样可以点「后悔」救回上一局面并继续游戏。
- 动画播放中 / 特技池弹窗打开 / 广告进行中点按无效，避免状态错乱。
- 回撤只还原棋盘与分数，不影响特技池库存与闪烁机会。
- 步数历史仅保存在内存中（上限 60 步），不做跨启动持久化。

## 特技加速模式

### 触发
- 仅当一次合并**新生成 512**（256 + 256）时触发；合成 1024 / 2048 等更高等级不触发。
- 触发后棋盘上会随机选中一个**空格子**，出现正方形磨砂按钮（⚡ ×512），带 10 秒加粗方形倒计时（最后 30% 变红并加强发光）与呼吸光效，绝不会盖住已有数字。
- 按钮所在格子随后被数字占用时，会自动转移到其他空格；棋盘无空格时直接入池，机会不丢失。
- 点击按钮可立即存入底池；10 秒结束自动渐隐入池。
- 倒计时期间再次合成 512：旧按钮立即入池，新按钮随机出现在新的空格中并重新计时。
- 单局最多获得 10 次；特技池上限 10 个。达到上限后合成为完全静默。

> 触发门槛由 `src/config.js` 的 `SPECIAL_TRIGGER_VALUE` 控制（默认 `512`），按钮文案与列表展示会自动跟随该常量。

### 底池与奖励
- 棋盘正下方固定显示缩短版「⚡ 特技池 [ 库存数 / 10 ]」，左侧同行为「后悔」按钮；有库存时高亮呼吸，无库存置灰。
- 点击入口弹出半透明列表，按 FIFO 显示 `#序号 512`，支持上下滑动。
- **每局第一次使用特技免广告**：点击任意条目直接 +2048，用于让玩家先体验效果；列表顶部会显示绿色「本局首次使用免广告」。
- 本局从第二次起，点击条目直接拉起激励视频广告（无二次确认），完整观看后：
  - 总分 +2048，条目移除，屏幕中央飘字「🚀 +2048 特技加速！」。
- 广告加载失败 / 中途关闭 / 5 秒超时：不扣库存、不发奖励，条目可重试。
- 点击条目后立即置灰，并有 1 秒冷却，避免重复请求广告 SDK。
- 免广告次数按“局”重置：点击「重新开始」或复活后继续当前局时，分别按新一局/当前局计算。
- 特技池队列持久化在 `fk2048_special_pool`，重进游戏不丢失；闪烁未入池的机会切后台时自动入池。

### 分数安全
- 分数使用整数累加并在 `Number.MAX_SAFE_INTEGER`（约 9×10¹⁵）处饱和，远超百万级冲榜需求。
- 最佳分以字符串形式存储，避免精度问题。

### 埋点
- 控制台输出 `[SpecialTrack]` 事件：`trigger` / `trigger_blocked` / `replace` / `expire` / `float_click` / `ad_complete` / `ad_incomplete` / `ad_fail` / `reward` / `free_use` / `revive` / `difficulty_select` / `undo` / `undo_ad_incomplete`，可直接接入上报 SDK。

## 调测开关（跳过广告）

调试复活、特技加速或后悔回撤时，不必每次看完广告，只需修改一个参数：

```javascript
// src/config.js 顶部
const DEBUG_SKIP_AD = false;  // 调试时改为 true
```

- `true`：复活 / 特技加速 / 后悔回撤都**不请求、不播放**激励视频，直接发放效果，并在底池下方显示红色「调测模式 · 跳过广告」标记，控制台输出 `[调测模式]` 警告与 `debug_skip_ad` 埋点。
- `false`：正式模式，正常播放激励视频。

⚠️ 上线前必须改回 `false`。

## 广告机制（复活 / 回撤复用同一广告位）

**触发时机**：游戏结束弹窗 → 点击「看广告复活」→ 播放激励视频 → 观看完成 → 继续游戏；后悔免费次数用尽后点击「后悔」同样拉起广告。

```javascript
// src/ads.js 中的关键配置
const adUnitId = 'adunit-xxxxxxxx'; // ⚠️ 必须替换为你在微信公众平台申请的激励视频广告位 ID

// 广告生命周期
1. 启动 2 秒后自动预加载 loadRewardedAd()
2. 游戏结束显示「看广告复活」按钮；后悔第 6 次起自动拉起广告
3. showRewardedAd(scene) 按场景展示（revive / undo）
4. onClose 回调中判断 res.isEnded
5. 观看完成 → 复活 onAdReward() / 回撤 onUndoAdReward()
6. 广告关闭后自动预加载下一条
```

## 快速开始

### 1. 微信开发者工具导入
```
打开微信开发者工具
→ 导入项目
→ 选择 minigame-native 目录
→ AppID 填入你的小游戏 AppID
→ 点击确定
```

### 2. 配置广告位 ID
编辑 `src/ads.js`，搜索 `adunit-xxxxxxxx` 并替换：
```javascript
const adUnitId = 'adunit-xxxxxxxx'; // 替换为你的激励视频广告位 ID
```
复活、特技加速与后悔回撤复用同一个激励视频广告位。在微信公众平台 → 流量主 → 激励视频 创建广告位获取。

### 3. 编译预览
点击工具栏「编译」→ 「预览」→ 真机调试

## 游戏逻辑核心

### 网格系统
- 4×4 / 5×5 网格（启动时选择）
- 滑动合并相同数字
- 新生成 2 (90%) 或 4 (10%)

### 评分系统
- 合并得分 = 新数字值
- 最高分本地持久化

### 判胜负
- 胜利：出现 2048（可继续游戏）
- 失败：无空位且无法合并

## 性能优化

- **requestAnimationFrame** 游戏循环
- **脏矩形渲染**（全量重绘，4x4 网格开销极小）
- **对象复用** Tile 对象池
- **CSS 变换动画** 用 scale/position 插值代替重排

## 布局说明

- 「最佳 / 得分」分数框紧跟棋盘上沿（与特技池距棋盘的间距一致，均为 26px）。
- 棋盘下方同一行：左侧「后悔」按钮，右侧缩短的特技池条，两者间距 12px；整行左右均与棋盘边框对齐，窄屏自动缩窄，不会超出棋盘左右范围。
